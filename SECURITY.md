# Security policy

This repository holds Lumovi's documentation. To report a vulnerability in Lumovi
itself, or in these docs, please follow
[Lumovi's security policy](https://github.com/Lumovi/Lumovi/security/policy):
report it privately through a
[GitHub security advisory](https://github.com/Lumovi/Lumovi/security/advisories/new),
and please don't open a public issue.

If you find a page that tells people to do something unsafe, that's worth reporting the same
way. Mistakes that aren't a risk can go in an
[issue](https://github.com/Lumovi/Lumovi-docs/issues/new/choose) here.

Lumovi works from the keyboard as well as the mouse. Press <kbd>?</kbd> anywhere to see the shortcut sheet. It's also in the command palette, and in the desktop app's **Help** menu.

  <img className="hidden dark:block" loading="lazy" src="https://cdn.jsdelivr.net/gh/Lumovi/Lumovi@main/docs/screenshots/shortcuts-dark-1x.webp" alt="The Lumovi keyboard shortcuts sheet, grouped into General, Lists, Open object, Terminal and Go to." />
</Frame>

<Note>
  Shortcuts are written for macOS. On Windows and Linux, use <kbd>Ctrl</kbd> wherever you see <kbd>⌘</kbd>. On a Mac, most shortcuts also work with <kbd>Ctrl</kbd>, but the ones that are only in the menus (<kbd>⌘</kbd><kbd>⇧</kbd><kbd>C</kbd>, <kbd>⌘</kbd><kbd>/</kbd>) and the editors' (<kbd>⌘</kbd><kbd>S</kbd>, <kbd>⌘</kbd><kbd>F</kbd>, <kbd>⌘</kbd><kbd>Z</kbd>) need <kbd>⌘</kbd>. The [terminals'](#terminals) keys differ more, so they're written out for both.
</Note>

## General

| Shortcut | What it does |
| --- | --- |
| <kbd>⌘</kbd><kbd>K</kbd> | Open the [command palette](/explore/finding-things). On the start screen, and on the page of every cluster in a [fleet](/clusters/fleet), it searches your clusters instead. |
| <kbd>/</kbd> | Filter the list |
| <kbd>⌘</kbd><kbd>R</kbd> | Refresh now |
| <kbd>⌘</kbd><kbd>[</kbd> or <kbd>Alt</kbd><kbd>←</kbd> | Back |
| <kbd>⌘</kbd><kbd>]</kbd> or <kbd>Alt</kbd><kbd>→</kbd> | Forward |
| <kbd>?</kbd> | Keyboard shortcuts |

### Desktop app only

These are in the app's menus, and work in the desktop app. A browser keeps <kbd>⌘</kbd><kbd>N</kbd> and <kbd>⌘</kbd><kbd>1</kbd>…<kbd>6</kbd> for its own windows and tabs, so when Lumovi runs [in your cluster](/server/overview), use the command palette for those instead.

| Shortcut | What it does | Menu |
| --- | --- | --- |
| <kbd>⌘</kbd><kbd>N</kbd> | Create from YAML | **File → New from YAML…** |
| <kbd>⌘</kbd><kbd>1</kbd> … <kbd>⌘</kbd><kbd>6</kbd> | Overview, Workloads, Pods, Services, Nodes, Events | **Go** |
| <kbd>⌘</kbd><kbd>⇧</kbd><kbd>C</kbd> | All clusters (back to the start screen) | **Go → All Clusters** |
| <kbd>⌘</kbd><kbd>/</kbd> | Keyboard shortcuts | **Help → Keyboard Shortcuts** |
| <kbd>⌃</kbd><kbd>&#96;</kbd> | Show or hide the [terminal](/debug/terminal) | **View → Terminal** |
| <kbd>⌃</kbd><kbd>⇧</kbd><kbd>&#96;</kbd> | New terminal | **View → New Terminal** |

In a [terminal](/debug/terminal) on a Mac, <kbd>⌘</kbd><kbd>N</kbd> opens another terminal instead of **New from YAML…**, and <kbd>⌘</kbd><kbd>W</kbd> and <kbd>⌘</kbd><kbd>K</kbd> close and clear the terminal instead of closing the window and opening the command palette. See [Terminals](#terminals).

## Go to a view

Press <kbd>G</kbd>, then a letter, within a second or so. Hover an item in the sidebar to see its letter.

| Keys | View | Keys | View |
| --- | --- | --- | --- |
| <kbd>G</kbd> <kbd>O</kbd> | Overview | <kbd>G</kbd> <kbd>J</kbd> | Jobs |
| <kbd>G</kbd> <kbd>W</kbd> | Workloads | <kbd>G</kbd> <kbd>C</kbd> | CronJobs |
| <kbd>G</kbd> <kbd>U</kbd> | Metrics | <kbd>G</kbd> <kbd>V</kbd> | Services |
| <kbd>G</kbd> <kbd>H</kbd> | Helm releases | <kbd>G</kbd> <kbd>I</kbd> | Ingresses |
| <kbd>G</kbd> <kbd>N</kbd> | Nodes | <kbd>G</kbd> <kbd>F</kbd> | ConfigMaps |
| <kbd>G</kbd> <kbd>M</kbd> | Namespaces | <kbd>G</kbd> <kbd>X</kbd> | Secrets |
| <kbd>G</kbd> <kbd>E</kbd> | Events | <kbd>G</kbd> <kbd>L</kbd> | Volume Claims |
| <kbd>G</kbd> <kbd>P</kbd> | Pods | | |
| <kbd>G</kbd> <kbd>D</kbd> | Deployments | | |
| <kbd>G</kbd> <kbd>S</kbd> | StatefulSets | | |
| <kbd>G</kbd> <kbd>A</kbd> | DaemonSets | | |

ReplicaSets, Autoscalers, Network Policies, Volumes, Storage Classes, API resources, [Right-sizing](/metrics/right-sizing), [add-on](/custom-resources/add-ons) pages and custom resources have no letter. Open them from the sidebar, or type their name into <kbd>⌘</kbd><kbd>K</kbd>.

<Tip>
  Single-key shortcuts like <kbd>G</kbd>, <kbd>/</kbd> and <kbd>?</kbd> don't fire while you type in a field or a terminal, or while a dialog or menu is open, so they never get in your way.
</Tip>

## Lists

| Shortcut | What it does |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> or <kbd>J</kbd> <kbd>K</kbd> | Move through the rows |
| <kbd>Home</kbd> <kbd>End</kbd> | First or last row |
| <kbd>PgUp</kbd> <kbd>PgDn</kbd> | Jump ten rows |
| <kbd>←</kbd> <kbd>→</kbd> | Previous or next page |
| <kbd>↵</kbd> | Open the focused row in the detail panel |
| <kbd>X</kbd> | Select the focused row |
| <kbd>⇧</kbd><kbd>X</kbd> | Select a range of rows |
| <kbd>⌘</kbd><kbd>A</kbd> | Select every row on the page |
| <kbd>Esc</kbd> | Clear the selection, then close the detail panel |

While the detail panel is open, moving through the list opens each row in turn. In the filter box, <kbd>↓</kbd> moves into the list and <kbd>Esc</kbd> leaves the box. See [Several at once](/changes/bulk) for what to do with a selection.

## The open object

| Shortcut | What it does |
| --- | --- |
| <kbd>.</kbd> | Open the actions menu: scale, restart, edit… |
| <kbd>⌘</kbd><kbd>⌫</kbd> | Delete the open object |
| <kbd>Esc</kbd> | Close the detail panel, or a Helm release's panel |

With a menu or a dialog open, <kbd>Esc</kbd> closes that first, and the panel stays open. The panel's edge can be dragged to resize it, or focused and moved with <kbd>←</kbd> <kbd>→</kbd>. Lumovi remembers its width. See [Object details](/explore/details).

## Dialogs

| Shortcut | What it does |
| --- | --- |
| <kbd>↵</kbd> | Confirm, once the dialog is ready: the same as its main button |
| <kbd>Esc</kbd> | Cancel, and change nothing |

Dialogs that delete, drain or uninstall open with the focus on **Cancel**, or on the field where you type the name, so a stray <kbd>↵</kbd> never confirms them. See [Changing things safely](/changes/safely).

## Editing YAML

| Shortcut | What it does |
| --- | --- |
| <kbd>⌘</kbd><kbd>S</kbd> | Review changes: the cluster checks the edit and shows a diff |
| <kbd>Tab</kbd> / <kbd>⇧</kbd><kbd>Tab</kbd> | Indent, or take the indent back |
| <kbd>⌘</kbd><kbd>F</kbd> | Search the YAML |
| <kbd>⌘</kbd><kbd>Z</kbd> / <kbd>⌘</kbd><kbd>⇧</kbd><kbd>Z</kbd> | Undo and redo |

<kbd>Esc</kbd> doesn't close the panel while you're editing, so a stray keystroke never loses your work. See [Edit YAML](/changes/yaml).

The editors in **Create from YAML** and in Helm's upgrade and install dialogs work the same way: there, <kbd>⌘</kbd><kbd>S</kbd> creates the objects, or reviews the values.

## The map

In an object's [Map](/explore/map) tab:

| Shortcut | What it does |
| --- | --- |
| <kbd>Tab</kbd> | Move from card to card, tracing each card's chain on the map |
| <kbd>↵</kbd> | Open the card's object on a map of its own, or, on a card of pods, show each pod |

## Charts

On the [Metrics](/metrics/usage-history) page and in every **Metrics** tab:

| Shortcut | What it does |
| --- | --- |
| Drag across a chart | Zoom in on that stretch of time (not on [Right-sizing](/metrics/right-sizing)'s charts, which always show their week) |
| <kbd>←</kbd> <kbd>→</kbd>, <kbd>Home</kbd> <kbd>End</kbd> | Read the values at earlier or later points in time |
| <kbd>Esc</kbd> | Hide the readout |
| Click a legend item | Show or hide that series |
| <kbd>Alt</kbd> or <kbd>⇧</kbd> and click a legend item (or <kbd>⌘</kbd> on macOS) | Show only that series; do it again to show them all |

## Logs

| Shortcut | What it does |
| --- | --- |
| <kbd>Esc</kbd> in the search box | Clear the search |

Everything else in the log viewer is a button or a chip. See [Logs](/debug/logs).

## Terminals

In the desktop app's [terminals](/debug/terminal), at the bottom of a cluster's pages. Their keys differ by platform:

| What it does | macOS | Windows and Linux |
| --- | --- | --- |
| Show or hide the dock, anywhere in a cluster | <kbd>⌃</kbd><kbd>&#96;</kbd> | <kbd>Ctrl</kbd><kbd>&#96;</kbd> |
| New terminal, anywhere in a cluster | <kbd>⌃</kbd><kbd>⇧</kbd><kbd>&#96;</kbd> | <kbd>Ctrl</kbd><kbd>⇧</kbd><kbd>&#96;</kbd> |
| New terminal, in a terminal | <kbd>⌘</kbd><kbd>T</kbd> or <kbd>⌘</kbd><kbd>N</kbd> | <kbd>Ctrl</kbd><kbd>⇧</kbd><kbd>T</kbd> |
| Close it, in a terminal | <kbd>⌘</kbd><kbd>W</kbd> | <kbd>Ctrl</kbd><kbd>⇧</kbd><kbd>W</kbd> |
| Clear it, in a terminal | <kbd>⌘</kbd><kbd>K</kbd> | None of Lumovi's: <kbd>Ctrl</kbd><kbd>K</kbd> is the shell's |
| Previous or next terminal | <kbd>⌘</kbd><kbd>⇧</kbd><kbd>]</kbd> and <kbd>⌘</kbd><kbd>⇧</kbd><kbd>[</kbd>, or <kbd>⌃</kbd><kbd>PgDn</kbd> and <kbd>⌃</kbd><kbd>PgUp</kbd> | <kbd>Ctrl</kbd><kbd>PgDn</kbd> and <kbd>Ctrl</kbd><kbd>PgUp</kbd> |
| Rename the terminal | <kbd>F2</kbd>, on its tab | <kbd>F2</kbd>, on its tab |
| Make the dock taller or shorter | <kbd>↑</kbd> <kbd>↓</kbd>, on its top edge | <kbd>↑</kbd> <kbd>↓</kbd>, on its top edge |

- <kbd>⌃</kbd><kbd>&#96;</kbd> and <kbd>⌃</kbd><kbd>⇧</kbd><kbd>&#96;</kbd> work anywhere in a cluster, in a terminal too. The start screen has no dock.
- On a Mac, <kbd>⌘</kbd><kbd>T</kbd>, <kbd>⌘</kbd><kbd>N</kbd>, <kbd>⌘</kbd><kbd>W</kbd> and <kbd>⌘</kbd><kbd>K</kbd> are the terminal's while a terminal has focus, as in Terminal and iTerm. Everywhere else they keep their usual meaning.
- On Windows and Linux, a shell keeps <kbd>Ctrl</kbd><kbd>W</kbd>, <kbd>Ctrl</kbd><kbd>K</kbd> and the rest for itself, so the dock's keys add <kbd>⇧</kbd>, as Windows Terminal's do. They, and the keys that switch terminals, work while the dock is open and has focus.

Other keys go to the terminal's shell, as in any terminal, <kbd>Ctrl</kbd> keys included. On Windows and Linux, <kbd>Ctrl</kbd><kbd>K</kbd> and <kbd>Ctrl</kbd><kbd>R</kbd> are the shell's there: click the page, or hide the dock, to use Lumovi's. On a Mac, the menus' <kbd>⌘</kbd> shortcuts, like <kbd>⌘</kbd><kbd>R</kbd>, still work.

## Start screen and command palette

| Shortcut | What it does |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move through clusters or results |
| <kbd>↵</kbd> | Open the cluster, or run the result |
| <kbd>Esc</kbd> | Close the palette |
| <kbd>?</kbd> | All shortcuts, once you've left the search box (in it, <kbd>?</kbd> is part of what you type) |

The command palette finds views, objects, namespaces and clusters, and the actions for the open object. See [Search, filters and ⌘K](/explore/finding-things).

## A fleet's page of clusters

When Lumovi shows a [fleet](/clusters/fleet), its first page has every cluster you may see, as cards.

| Shortcut | What it does |
| --- | --- |
| <kbd>/</kbd> or <kbd>⌘</kbd><kbd>K</kbd> | Go to the search box |
| <kbd>↓</kbd> | From the search box, move to the first card |
| <kbd>Tab</kbd> | Move to the next card |
| <kbd>↵</kbd> | Open the cluster |
| <kbd>Esc</kbd> | Leave the search box |
| <kbd>⌘</kbd><kbd>R</kbd> | Ask every cluster again now |
| <kbd>⌘</kbd><kbd>[</kbd> <kbd>⌘</kbd><kbd>]</kbd> | Back and Forward, through the filters, labels and grouping you picked |
| <kbd>?</kbd> | Keyboard shortcuts |

In **Find a workload**, <kbd>↑</kbd> <kbd>↓</kbd> move through the workloads it found, <kbd>↵</kbd> opens one in its cluster, and <kbd>Esc</kbd> closes it.
